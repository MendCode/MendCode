Durable facts the agent keeps across sessions, in three scopes: user (every project), project, session. Retrieval picks what is relevant for each message; what the agent sees is bounded.
Model tools: memory (status, categories, list, search, context, add, update, delete, propose) and memory_graph (overview, search, upsert_fact, link, validate); both are deferred (find them with tool_search) and writes are approved calls. Search before adding, update instead of duplicating, store only durable facts, never transient status, and never secrets. Proposals (propose) wait for the user in Pending, following per-category policies.
The user's page is /memory (tabs: Pending, Saved, Archived, Dream, Graph, Policies, Evolution, Extraction, Sharing): approve or reject proposals, edit, archive, change scope, pin. Dream is the daily consolidation pass; its time and policies are set there.
CLI (add, edit, delete, apply, reject: the user's terminal; refused from your shell): {{program}} memory [status] | preview [query] | list [--status saved|pending|archived] | search "query" [--limit N] | add [--user] [--category C] "text" | edit <id> "text" [--scope global|project] | delete|apply|reject <id>. Add --dir D for another data dir.
Defaults: using saved facts in the prompt and generating them after a turn are both OFF until the user turns them on; approval of generated facts is ON. Settings (user's /settings or the /memory tabs; never change them yourself): [[setting:memoryEnabled]] gates proposals and retrieval; [[setting:memoryUse]] injects saved facts into the prompt; [[setting:memoryGenerate]] extracts after a turn; [[setting:memoryRequireApproval]] sends extractions to Pending. Caps: [[setting:memoryMaxPromptTokens]] (10,000), [[setting:memoryMaxEntries]] (50), [[setting:memoryProjectMaxEntries]] (3), [[setting:memoryGlobalCompactionMaxEntries]]; per-category [[setting:memoryPolicies]] (auto|review|never); per-project overrides [[setting:memoryProjects]]. Maintenance: [[setting:memoryMaintenance]] and [[setting:dreamConsolidationPolicy]] (disabled|preview|auto-consolidate); Dream runs on /dream and, when [[setting:dreamAt]] (HH:MM) is set, daily; [[setting:dreamMaxTokens]] bounds a run. Evolution ([[setting:evolution]] off|observe|suggest|auto-safe, off by default) proposes instruction and workflow candidates; workflows only with [[setting:evolutionWorkflows]]. /remember saves one fact now and /wiki manages the project wiki (the user types them).
Models (roles memoryExtractor, memoryAssistant, memoryConsolidator: {{program}} docs models) and sharing as Markdown are in the Extraction and Sharing tabs.
If the agent "forgot": check it was saved (search), that memoryUse is on, and the scope; absence from the prompt is the usual cause.
