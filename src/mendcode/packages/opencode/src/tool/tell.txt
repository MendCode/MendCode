Send text and selected attachments to one explicit MendCode session in the same project.

This queues an auditable session message for the target session. Attachments on the current user message are forwarded automatically; use files for absolute local paths or userAttachments for named attachments from earlier user messages. It never shares unselected history, reasoning, permissions, secrets, or model context. Same-workspace messages are delivered automatically to the target prompt queue; if the target is busy, delivery waits for its next idle boundary without interrupting it. Delivery remains awaiting response until the target finishes, then its final text and attachments return automatically to the source session without creating an acknowledgement loop.
