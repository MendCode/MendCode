List recent MendCode conversations in the current project as bounded session descriptors, including historical conversations. This is not a list of active agents. The limit controls result count, not activity or presence.

The result contains only explicit session IDs, titles, lifecycle state, short activity, workspace identity, and update time. It never reads or exposes transcript text, files, reasoning, permissions, secrets, or provider context. Use an exact session ID with tell only when there is a concrete reason to contact that conversation. Runtime state is the current server's observation: unknown means no status is available, idle does not prove an open terminal, and busy/retry does not establish file ownership. updatedAt is not a heartbeat. Do not infer ongoing work from titles, recency, or list membership, and do not wake historical sessions just to ask whether they are editing files.
