Add expiry to `LruCache`. `new LruCache({ max, ttlMs?, now? })` takes an optional default time-to-live in milliseconds and an optional clock (`now: () => number`, defaults to `Date.now`) so tests don't have to sleep. `set(key, value, ttlMs?)` can override the ttl for one entry. An entry expires ttlMs after it was last set (reading it doesn't extend it), and an expired entry behaves as if it isn't there: `get`, `has`, `size`, `keys` and `delete` ignore it, and it never forces a live entry out. Without a ttl nothing expires. Add tests for it.
