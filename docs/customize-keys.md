# Customize keys

Every row of the `/customize` page is a key of the terminal settings (`<data dir>/tui/profile.json`). Each key is also the name `customize_ui` and `api.settings.get/set` take, and the name a profile's `activate.tuiProfile` may carry (a profile may not set the keys that start things or touch the clipboard, see [customize](customize.md)). The page groups them in the sections below; the label is what the page calls the row. Allowed values, types and defaults of this version: `mendcode control-plane tui schema`; the values now: `mendcode control-plane terminal settings`.

A test holds this list to the page: a row added to `/customize` without a line here fails it.

What each key changes on screen, in a user's words, is `PROFILE_KEY_HELP` (packages/protocol/src/tui-key-help.ts; a test holds it to every key). The model searches it with `customize_ui {"action":"keys","query":"top bar"}`, which returns the matching keys with their type, allowed values, default and current value and asks for no approval; without a query it lists every key name. `mendcode docs screen-parts` maps every part of the screen, top to bottom, to its keys.

Rows that remove a part outright: `showTopbar` (the row above the session), `panelHeader` (the right panel's first row), `sidebarHeader` (the session list's title row), `showStatus` (the footer under the prompt), `showTasks` (running sub-agents and background commands over the prompt), `homeHeader` (the home screen's first row: folder, product, version), `homePanel` (the session list or actions under the home logo), `showPlaceholder` (the empty prompt's example text; `placeholderText` replaces it). `assistantName` is the text of the assistant's label; set, the label shows whatever `assistantLabel` says (your own label is `username` with `showUsername`).

Rows that also have a command of their own (the user types it; it opens the row or toggles it, and where it takes an argument that value is applied): `/view`, `/vim`, `/multiline`, `/accessible`, `/prompt-mode`, `/prompt-chrome`, `/presentation`, `/message-rendering`, `/submit-scroll`, `/timestamps`, `/thinking`, `/scrollbar`, `/jump-to-latest`, `/mascot`, `/comments`, `/activity`, `/username`, `/terminal-title`, `/tips`, `/sticky-prompt` and `/raw`.

Look settings that live in the daemon, not in the profile: `projectThemes` maps a project's absolute directory to a theme name and wins over the profile's `theme` and the global `theme` there (`/theme` in that project updates it); `MENDCODE_REDUCED_MOTION=1` (or screen-reader mode, [accessibility](accessibility.md)) stops the animated spinner and ticking animations in the compaction card.
